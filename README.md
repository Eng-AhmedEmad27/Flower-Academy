##  Flow Academy | Online Course Learning Platform

Flower Academy is a modern, highly responsive e-learning ecosystem inspired by platforms like Udemy and Coursera. Built with HTML, CSS, and JavaScript**, this front-end platform provides a clean, attractive, and seamless UI/UX designed to connect students and instructors through interactive learning experiences and intuitive web design.

### 🌟 Key Platform Features

* Interactive Learning: Video lectures, assignments, quizzes, and automated certificate generation upon completion.
* Dual Dashboards: Custom tailored experience for both Students (progress tracking, wishlist) and Instructors (course creation, analytics).
* Smart Catalog: Advanced search, dynamic filtering, and category navigation.
* Core Management: Secure user authentication, payment gateway integration, discussion forums, and admin panel control.
